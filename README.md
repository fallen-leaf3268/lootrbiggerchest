# Lootr Big Chest

扩展 Lootr 模组所有容器的容量，支持固定尺寸或加权随机尺寸。

## 兼容的容器

| 容器 | 原版尺寸 | 行范围 | 列范围 |
|------|---------|-------|-------|
| Lootr 箱子 | 3×9 | 1~20 | 1~32 |
| Lootr 木桶 | 3×9 | 1~20 | 1~32 |
| Lootr 潜影盒 | 3×9 | 1~20 | 1~32 |
| Lootr 运输矿车 | 3×9 | 1~20 | 1~32 |

## 依赖

- **Minecraft** 1.20.1
- **Forge** 47.3+
- **Lootr** 0.7+

## 配置

配置文件位于 `config/lootrbigchest-common.toml`：

### 固定尺寸

```toml
["箱子"]
行数 = 3     # 1 ~ 20
列数 = 9     # 1 ~ 32
```

四种容器（箱子、木桶、潜影盒、箱子矿车）各自独立配置。

### 随机尺寸

若配置了 `随机容量` 列表，则忽略固定行列，从列表中按权重随机选取：

```toml
["箱子"]
随机容量 = ["3,9,50", "6,9,30", "9,12,20"]
# 格式: "行,列,权重"
# 留空则使用固定行列
```

每个容器在首次打开时确定尺寸并持久化保存。

## 注意事项

- 配置修改后即时生效，无需重启
- 已存在的旧容器保持首次打开时确定的尺寸不变
- 容器 GUI 会自动适配不同尺寸
