# Lootr Bigger Chest

扩展 Lootr 箱子、木桶、潜影盒和运输矿车的容量，支持固定尺寸或加权随机尺寸。新建的 Lootr 自定义库存及 `MenuBuilder` 入口沿用 Lootr 原有行为。

## 兼容的容器

| 容器 | 原版尺寸 | 行范围 | 列范围 |
|------|---------|-------|-------|
| Lootr 箱子 | 3×9 | 1~20 | 1~32 |
| Lootr 木桶 | 3×9 | 1~20 | 1~32 |
| Lootr 潜影盒 | 3×9 | 1~20 | 1~32 |
| Lootr 运输矿车 | 3×9 | 1~20 | 1~32 |

## 依赖

- **Minecraft** 1.20.1
- **Forge** 47.3+
- **Lootr** 0.7+

## 配置

配置文件位于 `config/lootrbiggerchest-common.toml`：

### 固定尺寸

```toml
["箱子"]
行数 = 3     # 1 ~ 20
列数 = 9     # 1 ~ 32
```

四种容器（箱子、木桶、潜影盒、箱子矿车）各自独立配置。

### 随机尺寸

若配置了 `随机容量` 列表，则忽略固定行列，从列表中按权重随机选取：

```toml
["箱子"]
随机容量 = ["3,9,50", "6,9,30", "9,12,20"]
# 格式: "行,列,权重"
# 留空则使用固定行列
```

每个容器在首次打开时确定尺寸并持久化保存。

### 玩家独立容器大小

```toml
玩家独立容器大小 = false
```

默认关闭。开启后，每个 Lootr 容器会为每名玩家在首次生成库存时，使用该容器类型的随机容量池独立计算一次尺寸并持久化；随机池为空时使用固定尺寸。

- 同一玩家再次打开同一容器时沿用原尺寸
- Lootr 刷新库存只刷新物品，不重新随机尺寸
- 关闭配置后，已有玩家尺寸保留，新玩家使用公共容器尺寸
- 旧玩家库存不会因开启该配置而重新随机或缩容
- 新建自定义容器和 `MenuBuilder` 入口保持 Lootr 原有行为
- 旧版扩展过的自定义库存保留既有容量与物品；带尺寸记录的库存继续按原尺寸打开

## 注意事项

- 配置修改后即时生效，无需重启
- 已存在的旧容器保持首次打开时确定的尺寸不变
- 容器 GUI 按容量拼接，超出当前窗口时自动缩放

## 资源包替换 GUI 材质

在资源包中提供以下同路径 PNG 即可修改本模组界面：

| 路径 | 固定尺寸 | 绘制方式 |
|------|----------|----------|
| `assets/lootrbiggerchest/textures/gui/panel.png` | 24×24 | 九宫格面板；横纵分界均为 0、4、20、24，四角保持 4×4，边线与中心拉伸 |
| `assets/lootrbiggerchest/textures/gui/slot.png` | 18×18 | 容器、玩家背包及快捷栏共用；外围 1 像素边框，中央 16×16 对齐物品区域 |

两张材质均为本模组原创灰色像素图。替换时保留上述尺寸和切片位置；界面整体缩放会同时作用于面板、槽位和物品。

可编辑源文件为 [panel.bbmodel](src/main/art/gui/panel.bbmodel) 和 [slot.bbmodel](src/main/art/gui/slot.bbmodel)，均在 Blockbench 中绘制并保存，包含内嵌材质与绘图历史。用 Blockbench 打开后，可在 Paint 中修改，再将图片导出为对应名称的 PNG，放入资源包中的上述路径。
